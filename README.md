Обяснение где что лежит:
1) В файле main.py находится основной код управления, он же интерфейс. Отсюда запускается программа.
2) В файле code.py находится вспомогательный код, обрабатывающий датафрейм и прочее (загрузка и обработка).
3) В файле models.py находится код для обучения моделий (обучение).
4) В файле analysis.py происходит обработка данных не относящаяся к изменению данных (графф и матрица)
